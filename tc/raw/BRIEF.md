# 任務簡報（統測版・二技版）：統測、二技國文「文言文」題目擷取與解析

ROOT = D:\字裡山河（Bash 下為 /d/字裡山河）。以下路徑都相對 ROOT。Python 要加 `-I`；在 Bash 印中文前先 `export PYTHONIOENCODING=utf-8`。

使用者是國文老師。我們已經做好國中版（基測、會考）與高中版（學測、指考），現在做技職版：
- **統測**（四技二專統一入學測驗，共同科目國文）101–115 學年度：考卷代號 tc101…tc115，資料夾 `tc/raw`，網站 `tc/site`。讀者是**技術型高中（高職）學生**。
- **二技**（二技統一入學測驗，共同科目國文）101–115 學年度：考卷代號 et101…et115，資料夾 `et/raw`，網站 `et/site`。讀者是**專科、科大要考二技的學生（含在職進修者）**。

以下以 `<k>` 代表 tc 或 et。

## 素材（全部來自技專校院入學測驗中心官方檔案）
- `<k>/raw/pages/<exam>/pNN.png`：試卷每頁 200dpi 圖（寬 1654px）。
- `<k>/raw/ruled/<exam>/pNN.png`：加藍色水平刻度線，每 100px 標一次 y（數字是原圖像素座標）。
- `<k>/raw/ocr/<exam>.json`：PDF 文字層（文字準確）。每頁 lines：t=文字、b=[x0,y0,x1,y1]，座標與頁圖相同。**用它定位最準**：題號那一行的 y0、最後一個選項那一行的 y1。
- `<k>/raw/ans/answers.json`：官方答案，`{"tc110":{"1":"B",...}}`。答案可能是 "#" 或 "送分" 或多個字母（一題多個答案皆給分），照實記錄並在 note 說明。原始答案頁圖在 `<k>/raw/ans/<exam>-p1.png`。
- 截圖：`python -I scripts/crop.py <exam> "<spec>" <k>/site/img/<id>.png`
  - spec 例：`"5:500-1700"`；跨頁 `"5:1800-2250;6:180-900"`；可加 x 範圍 `"5:500-1700:100-1600"`。
  - **每張截圖都用 Read 打開檢查**：題號（或「X-Y 為題組」說明句）到最後一個選項完整、引文完整、沒切到上下題。上下各留約 15px。

試卷結構：統測國文是單選題（約 38 題），108 年起另有「寫作測驗」——寫作測驗**不收**。二技國文是單選題（約 50 題）。題組常見「閱讀下文，回答 X–Y 題」。

## 收錄範圍
收錄：題幹、引文或選項的主要材料是文言（古文、史傳、諸子、筆記、書信、古典詩詞曲），或考文言字詞／虛詞／句意／文化常識／應用文（書信用語、題辭、對聯、柬帖）且選項為文言原句或文言用語的題目。白話文章中引用文言、必須讀懂文言才能作答的題目也收（文白對讀）。
不收：純白話、現代詩、純字形字音成語題（除非選項就是文言原句）、寫作測驗。拿不準就收，並在 note 註明。
一個題組＝一筆（questions 陣列放全部子題）；單題一題一筆。

## 輸出
每份考卷寫 `<k>/raw/data/<exam>.json`（UTF-8）：
```json
{"exam":"tc113","label":"113統測","total_questions":38,
 "items":[
  {"id":"tc113-13","exam":"tc113","nums":[13,14],"form":"題組",
   "crop":"5:500-1990","img":"img/tc113-13.png",
   "source":"《世說新語‧自新》","author":"劉義慶","genre":"筆記小品",
   "types":["比較閱讀","文意推論"],
   "passage":"文言原文（依試卷正確謄寫；文白對讀只放文言部分；字詞題可放選項中的文言句）",
   "translation":"通順白話翻譯",
   "keywords":[{"w":"患","m":"憂慮、禍害"}],
   "questions":[
     {"n":13,"qtype":"單選","stem":"…","options":{"A":"…","B":"…","C":"…","D":"…"},"answer":"B",
      "explain":"正解理由＋逐項說明錯在哪（引原文證據）","skill":"解題小撇步：一句可遷移的解題動作"}
   ],
   "difficulty":"易|中|難",
   "official":"",
   "note":"給老師看的備註（收錄理由、出處待查、送分等，可空）"}
 ]}
```
- id 用 `<exam>-<第一題題號兩位數>`，例如 tc113-05。img 是 `img/<id>.png`（相對 `<k>/site`）。
- 固定分類（只用這些詞）：
  - genre：寓言故事、史傳人物、說理議論、山水遊記、筆記小品、書信序跋、經典語錄、古典詩詞曲、其他（應用文、題辭、對聯、跨文本字詞題可歸「其他」）
  - types（可多選）：字詞解釋、虛詞句式、句意理解、文意推論、主旨寓意、人物情感、寫作手法、比較閱讀、文化常識、典故出處、詩詞賞析
  - form：單題、題組；qtype：單選
- 選項有多篇不同出處的文言句（如字詞比較題）時：source 寫「綜合（多篇古文）」，passage 放題幹中的文言引文或空字串。

## 品質要求
- 題目、選項以試卷文字層為準謄寫。答案以官方答案為準。
- **explain、skill、translation 是給學生看的**：口語、清楚，先抓大意再講證據；不要寫「官方」「疑義」「試題說明」「評分原則」「命題」這類字眼——那些資訊放 official 或 note。統測版可偶爾用貼近職場或生活的比喻幫助理解，但不要硬扯。
- 每題都要逐一說明 A–D 每個選項對或錯。
- 「曰」字照原文寫，不要寫成「日」。
- 出處不確定可 WebSearch 查證；查不到就在 source 寫「出處待查」，不要編。
- 只動你負責的考卷檔案與對應截圖。完成後用 `python -I -c "import json;json.load(open(...,encoding='utf-8'))"` 確認 JSON 合法。回報：每份收錄幾筆（單題、題組、題數）、有疑慮的題目。
