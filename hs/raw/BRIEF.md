## 素材（全部來自大考中心官方檔案）
- `hs/raw/pages/<exam>/pNN.png`：試卷每頁 200dpi 圖（寬約 1650px）。
- `hs/raw/ruled/<exam>/pNN.png`：同上加藍色水平刻度線，每 100px 標一次 y（**數字就是原圖像素座標**，不要用 Read 顯示時縮放後的座標）。
- `hs/raw/ocr/<exam>.json`：PDF 文字層（不是 OCR，文字準確）。每頁 lines：t=文字、b=[x0,y0,x1,y1]，座標與頁圖相同。**用它定位最準**：找題號那一行的 y0、最後一個選項那一行的 y1。
- `hs/raw/ans/ans_text.json`、`hs/raw/ans/<exam>-p1.png`：官方選擇題答案（多選題答案如 "ACE"）。
- `hs/raw/ref/*.txt`：非選擇題評分原則／參考答案（學測 101–106、111–115；指考 101–106）、閱卷說明。
- 截圖工具：`python -I scripts/crop.py <exam> "<spec>" hs/site/img/<id>.png`
  - spec 例：`"5:500-1700"`（第5頁 y=500~1700）；跨頁：`"5:1800-2250;6:180-900"`；可加 x 範圍 `"5:500-1700:100-1600"`。
  - **每張截圖都用 Read 打開檢查**：題號（或「X-Y為題組」說明句）到最後一個選項完整、引文框完整、沒切到上下題。上下各留約 15px。

考卷代號：xc101＝101學測 … xc115＝115學測（111 起是「國語文綜合能力測驗」）；zk101＝101指考 … zk110＝110指考。

## 收錄範圍
收錄：題幹、引文或選項的主要材料是文言（古文、史傳、諸子、筆記、書信、古典詩詞曲），或考文言字詞／句意／文化常識且選項為文言原句的題目。白話文章中引用文言、必須讀懂文言才能作答的題目也收（文白對讀）。
不收：純白話、現代詩、純字形字音成語題（除非選項就是文言原句）。拿不準就收，並在 note 註明。
**非選擇題**：只要是文言材料（例如文言文閱讀解析、翻譯、比較）就收，qtype 標「非選」。學測 111 起的混合題，選擇部分照常、非選部分標「非選」。
一個題組＝一筆（questions 陣列放全部子題）；單題一題一筆。

## 輸出
每份考卷寫 `hs/raw/data/<exam>.json`（UTF-8）：
```json
{"exam":"xc113","label":"113學測","total_questions":36,
 "items":[
  {"id":"xc113-13","exam":"xc113","nums":[13,14,15],"form":"題組",
   "crop":"5:500-1990","img":"img/xc113-13.png",
   "source":"《世說新語‧自新》","author":"劉義慶","genre":"筆記小品",
   "types":["比較閱讀","文意推論"],
   "passage":"文言原文（依試卷正確謄寫；文白對讀只放文言部分）",
   "translation":"通順白話翻譯",
   "keywords":[{"w":"患","m":"憂慮、禍害"}],
   "questions":[
     {"n":13,"qtype":"單選","stem":"…","options":{"A":"…","B":"…","C":"…","D":"…"},"answer":"B",
      "explain":"正解理由＋逐項說明錯在哪（引原文證據）","skill":"解題小撇步：一句可遷移的解題動作"},
     {"n":22,"qtype":"多選","stem":"…","options":{"A":"…","B":"…","C":"…","D":"…","E":"…"},"answer":"ACE","explain":"…","skill":"…"},
     {"n":"三","qtype":"非選","stem":"題目要求","options":{},"answer":"",
      "ref_answer":"參考答案／作答要點","ref_official":true,"explain":"怎麼想、怎麼寫","skill":"…"}
   ],
   "difficulty":"易|中|難",
   "official":"官方評分原則／閱卷說明中與此題相關的摘要（給老師看，可空）",
   "note":"給老師看的備註（收錄理由、出處待查、疑義等，可空）"}
 ]}
```
- 非選題的 n 可用試卷上的大題編號（如 "一"、"三"）或混合題題號；`ref_official`：參考答案取自官方檔案為 true，你自己擬的為 false。
- 固定分類（只用這些詞）：
  - genre：寓言故事、史傳人物、說理議論、山水遊記、筆記小品、書信序跋、經典語錄、古典詩詞曲、其他
  - types（可多選）：字詞解釋、虛詞句式、句意理解、文意推論、主旨寓意、人物情感、寫作手法、比較閱讀、文化常識、典故出處、詩詞賞析
  - form：單題、題組；qtype：單選、多選、非選

## 品質要求
- 題目、選項以試卷文字層為準謄寫（可直接從 ocr json 取字）。答案以官方答案為準。
- **explain、skill、translation 是給高中生看的**：口語、清楚，先抓大意再講證據；不要寫「官方」「疑義」「試題說明」「評分原則」「命題」這類字眼——那些資訊放 official 或 note。
- 多選題要逐一說明 A–E 每個選項對或錯。
- 出處不確定可 WebSearch 查證；查不到就在 source 寫「出處待查」，不要編。
- 只動你負責的考卷檔案。完成後回報：每份收錄幾筆（單題、題組、非選題數）、有疑慮的題目。
