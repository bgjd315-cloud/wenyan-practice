# 文言文練習場

國中基測（90 年）到國中教育會考（115 年）的文言文題目練習網站，共 568 題。每題附考卷原題截圖、白話翻譯、重要字詞、逐選項解析與解題小撇步。

**網站：** https://bgjd315-cloud.github.io/wenyan-practice/

## 資料夾
- `site/`：網站本體。`index.html` 可直接用瀏覽器打開，不需要伺服器。
- `site/img/`：每題的原題截圖。
- `site/art/`：網站插圖。
- `raw/data/`：每份考卷的題目資料（含給老師看的官方說明、疑義釋復、出處備註）。
- `raw/research.md`：文言文解題方法的研究整理與來源。
- `scripts/build.py`：由 `raw/data/` 產生 `site/data.js`。

題目來源：國立臺灣師範大學心理與教育測驗研究發展中心公布之歷屆試題，僅供教學練習使用。
