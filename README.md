# 字裡山河：文言閱讀練習

- **國中版**：國中基測（90 年）到國中教育會考（115 年），568 題。
- **高中版**：學測 101–115、指考 101–110，503 題（含多選、非選）。

每題附考卷原題截圖、白話翻譯、重要字詞、逐選項解析與解題小撇步。

**網站：** https://bgjd315-cloud.github.io/wenyan-practice/

## 資料夾
- `site/`：國中版網站。`hs/site/`：高中版網站。`index.html` 可直接用瀏覽器打開，不需要伺服器。
- `site/img/`：每題的原題截圖。
- `site/art/`：網站插圖。
- `raw/data/`、`hs/raw/data/`：每份考卷的題目資料（含給老師看的官方說明、疑義釋復、出處備註）。
- `raw/research.md`、`hs/raw/research.md`：國中、高中文言文解題方法的研究整理與來源。
- `scripts/build.py`：產生網站資料（`python scripts/build.py` 國中版、`python scripts/build.py hs` 高中版）。

題目來源：國立臺灣師範大學心理與教育測驗研究發展中心、大學入學考試中心公布之歷屆試題，僅供教學練習使用。
